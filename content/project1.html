01

准备环境与创建数据库

  1. 准备可使用 Microsoft Access 的 Windows 环境。Mac 用户可使用学校机房或已有的 Windows 远程环境。Python / C++ 用于后续生成随机数据。
  2. 下载并解压上方的实验数据包，确认包含 student.txt 等 7 个文件。
  3. 打开 Access，选择“文件 → 新建 → 空白数据库”，命名为 university_A1.accdb，保存到自己的实验目录。
  4. 进入“创建 → 表设计”，熟悉字段名称、数据类型、字段属性和主键设置。
完成标志：能打开保存后的数据库，并进入表的设计视图。课件同时接受 .mdb 与 .accdb 格式；提交时使用本学期指定格式。
02

创建 7 张表，导入原始数据

先对照数据字典建表，再把文本数据追加到对应的表。这样可以明确控制字段类型与复合主键。

  1. 以 student 为例，依次建立 sid, sname, sex, age, year, gpa 字段。将 sid 设为“数字 / 长整型”，将 gpa 设为“数字 / 双精度型”。文本字段使用“短文本”。
  2. 在设计视图中选中 sid 行，点击“主键”，然后保存为 student。对复合主键，按住 Ctrl 选中所有主键字段的行选择器，再点击“主键”。
  3. 选择“外部数据 → 新数据源 → 从文件 → 文本文件”；部分旧版本直接显示“文本文件”。选择对应 TXT，并选择“向表中追加一份记录的副本”。
  4. 导入方式选“分隔符号”，分隔符选 Tab（制表符），文本限定符选双引号，并勾选“第一行包含字段名称”。检查预览中每一列的对应关系。
  5. 完成导入后打开表，检查记录数、姓名、院系名称和小数。若出现导入错误表，先检查错误原因，不要在已有数据上盲目重复导入。
  6. 对其余 6 张表重复操作。建议顺序：dept → student → prof → course → major → section → enroll。
两个容易出错的地方：文件是 Tab 分隔，姓名中的逗号不是分隔符；course 的主键是 (cno, dname)，课程号不能单独设为唯一。不要额外添加自动编号的 ID 字段。

导入原始数据后，在“创建 → 查询设计 → SQL 视图”中分别运行计数查询，并与数据字典核对。例如：

SELECT Count(*) AS row_count FROM [student];

原始 student 表应有 104 条记录。

操作参考：Microsoft 文本导入说明 ↗

03

使用 SQL 插入一条记录

先查询现有的最大学号，再为新记录选一个未使用的 sid。每次只运行一条 SQL；运行下面的示例前，确认 10001 尚未使用。

SELECT Max([sid]) AS max_sid FROM [student];
INSERT INTO [student] ([sid], [sname], [sex], [age], [year], [gpa])
VALUES (10001, 'Demo Student', 'f', 20, 2, 3.50);

随后单独运行查询，验证写入结果，并保存 SQL 与结果截图：

SELECT * FROM [student] WHERE [sid] = 10001;
完成标志：能查到新增记录，且表的记录数比插入前增加 1。[year] 等字段名用方括号包裹，避免名称与函数或关键字冲突。

语法参考：Microsoft Access INSERT INTO ↗

04

生成并插入超过 5000 条随机记录

课件要求使用 C++ 或 Python 为 student 生成超过 5000 条随机元组，并使用 SQL 插入。5000 条整不满足要求；可以选择生成 6000 条。

  1. 查询数据库中当前的最大 sid，从其后连续分配新编号。为随机数设置固定种子，便于复现实验。
  2. 自行编写生成程序。姓名可使用合成名称，sex 与原始数据的取值约定一致；年龄、年级和 GPA 的取值范围由你设计，并在报告中解释。
  3. 把结果保存为带字段名的 Tab 分隔文件。检查总行数、列数、数据类型和 sid 唯一性。
  4. 一种可行的插入流程：将生成文件导入临时表 student_generated，使用下面的 SQL 把记录追加到 student。也可以通过数据库驱动逐条执行参数化 INSERT。
  5. 插入前先备份数据库。记录插入前后的数量，确认增量等于生成数量，并保存程序、SQL、结果和截图。
INSERT INTO [student] ([sid], [sname], [sex], [age], [year], [gpa])
SELECT [sid], [sname], [sex], [age], [year], [gpa]
FROM [student_generated];
查看生成程序的思路
读取现有最大 sid，记录插入前的行数
设置随机种子
重复 N 次（N > 5000）：
    sid = 最大 sid + 当前序号（从 1 开始）
    生成姓名、性别、年龄、年级和 GPA
    检查字段范围，输出一条记录
使用 SQL 将生成记录插入 student
检查：插入后行数 − 插入前行数 == N

这是实现思路；请独立完成生成程序，并在报告中解释你的设计。

不要重复执行同一批插入。重复学号会触发主键冲突。临时表导入完成并不等于实验完成，还需通过 SQL 写入最终的 student 表。

TROUBLESHOOTING

常见问题

为什么导入后所有内容都在同一列？

确认选择了“分隔符号”与 Tab（制表符），并勾选首行包含字段名称。不要选择逗号分隔，姓名本身可能含有逗号。

为什么提示主键重复或无法追加记录？

检查是否重复导入了同一批数据，以及 course、major、section、enroll 是否正确设置复合主键。随机数据的 sid 应从当前最大 sid 之后分配。不要通过删除主键来绕过错误。

为什么 GPA 的小数没有正确显示？

在设计视图检查 gpa 和 grade 的字段大小是否为双精度型，并检查小数位显示设置。若此前用整型导入造成小数丢失，需要修正字段类型后重新导入原始数据。

可以在 Mac 或网页中直接完成 Access 实验吗？

本网页提供教程和下载，不执行 Access 数据库操作。Access 需要 Windows 环境；Mac 用户请安排学校机房或已有的 Windows 远程环境。不要未经课程允许改用其他 DBMS 替代提交。

报告模板里的姓名、学号和环境可以保留吗？

模板中的姓名、学号、Windows XP 与 Access 2003 等仅为历史示例。请填写自己的信息和实际实验环境，用自己的实验过程与截图替换占位内容。
