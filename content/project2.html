PROJECT 02

SQL 查询与索引

在 University 数据库上独立完成 12 个查询，并比较索引对查询的影响。

1. 准备两个数据库

使用原始 University 数据集建立 university_A2.accdb；课件建议恢复原始的 104 条学生记录，便于核对结果。先备份 Project 1，不要直接覆盖其随机数据实验结果。

Sailors / Boats / Reserves 数据仅用于课堂演示，可另存为 lab2.accdb，不属于本次作业的 University 数据。

2. 先完成查询练习

  1. 在 Access 中创建查询并切换到 SQL 视图。
  2. 用 Boats 表练习条件筛选，再关联 Reserves 与 Sailors，观察连接条件对结果的影响。
  3. 练习按年份筛选、分组与 HAVING。聚合前先想清楚统计对象是记录数还是不同的学生 / 船只。

3. 独立完成以下 12 题

  1. 列出所在院系博士生数量少于 50 的教师姓名。
  2. 列出 GPA 最低的所有学生姓名，包括并列者。
  3. 对每个 Computer Sciences 班级，列出课程号、班号以及选课学生的平均 GPA。
  4. 列出选课人数超过 6 人的班级的课程名、课程号与班号。
  5. 列出选课班级数量最多的学生姓名与学号，包括并列者。
  6. 列出至少有一名未满 18 岁主修学生的院系名称。
  7. 列出修读任一 College Geometry 课程的学生姓名与主修专业，练习 LIKE 模式匹配。
  8. 列出没有任何主修学生修读 College Geometry 的院系名称及博士生数量。
  9. 列出同时修读 Computer Sciences 课程和 Mathematics 课程的学生姓名。
  10. 计算 Computer Sciences 主修学生中最大年龄与最小年龄的差。
  11. 对至少有一名 GPA 低于 1.0 的主修学生的院系，列出院系名称及其全部主修学生的平均 GPA。
  12. 列出修读全部 Civil Engineering 课程的学生学号、姓名与 GPA。
每题仅用一条 SQL，不创建临时表。结果不能重复，仅在必要时使用 DISTINCT。将查询命名为 Query1 至 Query12。课程与班级的关联需包含完整复合键。

4. 比较索引并撰写报告

选择与 student 表有关的查询，在相同数据和条件下比较建立适当索引前后的行为与耗时。记录索引字段、数据规模、测量方法及结果；小数据集可能观察不到明显差异，不要虚构加速效果。

提交 report_A2.doc / .docx / .pdf 与 university_A2.mdb / .accdb。报告应包含 SQL、结果、分析和索引实验。按 学号-姓名-Project-2.zip 打包。
