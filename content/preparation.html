ENVIRONMENT

软件环境

Microsoft Access

前五次实验涉及 Access 数据库。请准备可运行 Access 的 Windows 环境，并通过学校授权渠道或 Microsoft 官方渠道获取软件。

Mac 用户应提前安排学校机房或已有的 Windows 远程环境。网页仅提供教程与下载，不在浏览器中运行 Access。不要在未获课程允许时用其他 DBMS 替代实验提交。

准备完成后，确认能启动 Access、新建一个空白数据库、保存并重新打开它。将系统与 Access 版本记录下来，供实验报告使用。

Python 或 C++

用于编写数据生成程序。选择自己熟悉的一种语言，确认能运行一段简单程序并将结果写入文本文件。Project 1 开放后再按具体要求生成数据。

Java 与 Maven

Project 3 将使用 JDK 17、Maven 和 JDBC。现在可以了解安装流程，具体示例代码随 Project 3 一同开放。

JDK 17 官方下载 · Apache Maven 下载 · Maven 安装说明

LAB REPORT

报告准备

在实验过程中及时记录，不要等最后再补截图。报告通常需要说明实验环境、操作步骤、程序与 SQL、运行结果、遇到的问题以及总结。

  • 姓名、学号、Project 编号与实际软件环境准确。
  • 代码与截图能够对应，说明观察到的结果。
  • 解释错误原因和修改过程，不只罗列截图。
  • 按各 Project 的要求命名报告和附件。

具体报告模板、题目和提交清单随对应 Project 开放。
