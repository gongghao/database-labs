PROJECT 03

Java 连接数据库

通过 JDBC 连接 University 数据库，在程序中执行建表、增删改查和 Project 2 的查询。

1. 配置 JDK 17 与 Maven

安装适合操作系统和芯片架构的 JDK 17、Apache Maven，打开新终端运行以下命令：

java -version
javac -version
mvn --version

如需配置变量，JDK 使用 JAVA_HOME，Maven 可使用 MAVEN_HOME，把对应的 bin 目录加入 PATH。原课件的 JAVA_SOME / MAVEN_SOME 为笔误；JDK 17 不需要额外添加独立的 jre/bin。

安装包从JDK 17 官方页面和Apache Maven 官网获取。课程仓库提供代码与数据，避免重复分发体积很大的安装程序。

参考：Maven 安装说明 · JDK 17 目录结构

2. 理解提供的示例

下载 Main.java 和 pom.xml。将 Java 文件放在 src/main/java/com/example/Main.java；提供的 POM 使用 UCanAccess 5.0.1。根据 JDK 17 配置编译插件与编译目标，并先尝试构建。

修改 DB_PATH 为自己电脑上的数据库绝对路径。Windows 字符串可使用双反斜杠或正斜杠；不要照抄示例中的个人目录。

原始 Main.java 查询 Boats / Reserves 演示表，并非 University 作业的完整实现。先用示例数据验证连接，再修改为自己的 University 操作。运行前备份数据库。

3. 逐项实现并验证

  1. 结合现有业务新建一张表，自行设计字段和主键，并在报告中解释原因。
  2. 删除刚创建的表。
  3. 在 student 表插入一条新的记录，再删除该记录。
  4. 修改 student 表中的一条记录，验证后恢复原始值。
  5. 通过 Java 执行 Project 2 的全部 12 条查询，读取并展示结果。

将每一步的 SQL、执行结果和异常处理记录下来。修改操作要有准确的 WHERE 条件；恢复前后应核对数据一致性。查询完成后关闭 ResultSet、Statement 和 Connection。
